# Componentes de terceiros

O dashboard compilado inclui React, React DOM, Scheduler, Lucide, xterm.js,
xterm FitAddon, estilos Tailwind e as fontes Inter e JetBrains Mono.
Os avisos de licença desses componentes estão em `licenses/` e devem acompanhar
a distribuição do frontend compilado. As dependências Python são instaladas
pelo pip e mantêm seus próprios avisos nos respectivos pacotes.
